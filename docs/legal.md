# Legal And Asset Hygiene

This repository is an unofficial community project for local Home Assistant
interoperability with compatible UniFi Drive / UNAS devices.

It has no affiliation, sponsorship, authorization, approval or endorsement from
Ubiquiti Inc., Home Assistant, HACS or their respective owners.
Product and project names such as UniFi, UniFi Drive, UniFi OS, Ubiquiti and
UNAS are used only as descriptive compatibility references.

The project must not contain official Ubiquiti logos, product artwork,
screenshots, website assets, copied UniFi OS / Drive web-interface templates,
firmware dumps, vendor JavaScript, vendor CSS, vendor HTML or proprietary
Ubiquiti source code.

Protocol and endpoint documentation in this repository records observed
interoperability behavior only. It is not a copy of, or a substitute for, any
Ubiquiti software, vendor documentation or vendor specification.

Release validation scans tracked files for common secret material, generated
artifacts, official or proprietary Ubiquiti assets, copied vendor web assets and
known proprietary license or copyright markers. If a future change needs
third-party material, document the license and attribution before committing it.
